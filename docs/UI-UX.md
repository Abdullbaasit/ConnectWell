# UI/UX changes
Warm cream, forest green, clay and gold preserve the inspected website identity. Nigerian community illustrations are bundled SVG assets, so the visual design does not require an image CDN.

Registration is the entry screen. Returning users can sign in. Capture family details, consent, loved-one preferences, language, mobility and Ibadan neighbourhood. The dashboard, Discover, Connections, calendar, profile, reflection, provider workspace and receipts follow.

Recommendations show plain-language reasons. Activity compatibility is a preference percentage, not clinical risk. Unsuitable movement is excluded for limited-mobility bookings. All peer/provider records are fictional. Peer requests are saved demo interactions, not real communications.

Mobile layouts stack forms and cards and use a menu button. Text and controls are larger than the earlier prototype. Browser visual QA has not been performed in this environment.
